# 今日瓦运 · 开局运势（GG Oracle）

> **不是游戏数据工具，而是玩家开局前的仪式工具。**

面向《VALORANT》玩家的开局娱乐决策工具：开游戏前抽一张卡，30 秒内得到今天的运势、幸运位置、幸运英雄、武器、皮肤、地图和一句战术建议，然后截图发群里——「今天软件让我玩烟位」。

## ✨ 功能

- **三选一抽卡 + 3D 翻牌揭晓**：星级渐显的开局仪式感
- **完整运势报告**：今日总运 / 幸运位置（四位置指数）/ 幸运英雄（契合度）/ 幸运武器（含今日不推荐）/ 幸运皮肤（含幸运颜色与饰品）/ 地图运势排行 / 今日 Advice
- **每日 Seed**：同人同天结果一致，绝不「不满意一直刷」；「改命」每天一次
- **半随机算法**：随机 + 近期未推荐去重，避免连续七天都是同一个位置
- **Canvas 分享卡**：750×1334 高清图片，长按保存 / 一键下载 / 复制文案发群
- **纯前端**：无后端、无登录，数据只存本地（localStorage，90 天历史）

## 🚀 快速开始

```bash
npm install     # 安装依赖
npm run dev     # 开发：http://localhost:5173
npm test        # 34 条单元测试（确定性算法 / 存储 / 分享卡渲染）
npm run build   # 生产构建（约 74KB gzip），产物在 dist/
```

技术栈：Vite + React 19 + TypeScript（严格模式）+ 原生 CSS 设计 token + Canvas 2D。
